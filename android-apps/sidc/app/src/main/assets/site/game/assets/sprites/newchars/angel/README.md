# Angel

Sprites provenientes de `Angelin.zip` localizado en Google Drive.

- `angel-01.png`: ataque/salto de Angel.
- `angel-02.png`: Angel pequeño con Sprunky; se usa para idle/caminar.
- `angel-03.png` y `angel-04.png`: ataques con traje de tiburón.
- `angel-05.png` y `angel-06.png`: impactos y patada.
- `angel-shark.png`: forma grande de tiburón durante la transformación.
- `game/assets/projectiles/angel-shark.png`: proyectil de tiburón.
- `game/assets/specials/angel-sprunkys.png`: especial de Sprunkys grandes.

El banco conserva las imágenes en RGBA y el motor controla el tamaño: Angel normal usa escala visual 0.56; la forma tiburón usa 1.08, cercana al porte de Miguel.
